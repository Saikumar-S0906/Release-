2. WHAT THE CODE IS DOING TODAY (audit findings)
------------------------------------------------------------------------------

2.1 Create → Tools is a wall of tiles
    File: app/src/main/java/com/pixijoy/ai/ui/board/create/BoardCreateHub.kt
    Four stacked groups, 2 columns on phone (3 on landscape-width, 4 on tablet):

      Fix (3):     Editor, Restore, Expand
      Cutout (5):  Remove BG, Stickers, People, Face swap, Scene
      Motion (4):  Make it Move, Talking photo, Slideshow, Video/GIF
      Compose (6): One photo six looks, Collage, Greeting, Portrait,
                   Remix from community, Export / Share

    Tile aspect is a constant CreateHubTileAspect = 1.15f.
    On a phone that is 18 tiles. That is why Tools feels stuffed.

2.2 Wrong shelf for several tiles
    - Remix (b_c14) is community/AI remix, listed under Tools → Compose.
    - "One photo, six looks" is the AI pack, listed under Tools → Compose.
    - Face swap, Scene, People are closer to AI than "tools".
    - Export / Share is a finish action, not a create tool.

2.3 Export / Share skips photo and shows stock art
    - Create: pick("export", pipeline.openExport) → navigate("b17_open")
      with NO photo gate (unlike Stickers, which uses stickerGate).
    - BoardFlow17Session.hero() = BoardFlowArt.baAfter
      (beautify "after" image — reads as Good Vibes / template).
    - User never gets Take photo / Gallery / Files first.

2.4 Create → AI is congested and duplicated
    - Full-width primary button: Make it Beautiful
    - Then tiles: Beautiful (again), Funny, Different
    - Then five era chips (80s / 90s / 2000s / Film / Now) that jump into
      Make it Different
    - Then Tell PixiJoy as a 96dp image banner, not a normal tile
    Beautiful is both a giant CTA and a tile. Eras + Different + Tell compete.

2.5 Create hub header
    When not embedded, Back AND Close both call onBack. Two exits, same action.

2.6 Explore is a catalog dump
    File: BoardDiscoverMain in BoardFlow2Host.kt
    One scroll: title, search, chips (All / Templates / Styles / Stickers),
    featured hero, 9 popular categories (3-wide on phone), trust footer.
    3 category tiles per row is tight. Featured + all categories on All chip
    is a second page of content.

2.7 Landscape is "add a column", not a layout
    boardGridColumns: compact=2, medium=3, expanded=4.
    Landscape phone width often hits Medium → 3 columns of 1.15 tiles in a
    short viewport = postage stamps. No landscape-specific Create/Explore.

2.8 Tablet is a poster, not two-pane work
    Create uses BoardListDetail when width >= 840dp.
    Right pane is a STOCK canvas image (selectedCanvasRes), not the live tool
    and not the user's photo.
    Explore / Community stay single-column phone layouts stretched wide.
    MainScaffold has a nav rail on expanded width; inner screens do not use it
    as a real work surface.

2.9 Clickable text still used as actions
    TextButton / Text+clickable examples:
      Explore "See all" (SectionHeader)
      Home "Explore" TextButton
      Different: Another style, Variations
      Tell: Regenerate, input method
      Community: People, Guidelines, Remix
      Editor tool chips as Text+clickable
    Primary/secondary should be BoardPrimaryButton / BoardOutlinedButton
    with 48dp min height. Text is for copy, not jobs.

2.10 Density from bible-as-law
    52dp CTAs, 16px body, PixiSpacing.xl on every screen, trust footer on
    many screens, 4 columns because "expanded". Brand color/icons are fine.
    The grid math is what makes it feel cheap and busy.

2.11 What is already in good shape (do not undo)
    - Bottom tabs: Home, Explore, Create, Community, My Stuff
    - Explore chips/categories mostly match labels
    - Photo gate exists and is used for Stickers (pattern to copy)
    - Pixi icon set (pj_ic_*) — keep using it
    - Brand gradient #6C4DFF → #FF5AA5
    - Competitive pack implementation exists; it is just filed in the wrong
      Create group and the hub is too crowded to find it

3. PRINCIPLES FOR THE FIX (so we do not re-bible the UI)
------------------------------------------------------------------------------

P1. One job per screen. Hub = pick a job. Tool = do the job. Result = save/share.
P2. Photo-first. If the job needs a photo, ask before showing a result canvas.
P3. Tools vs AI is about the user's mental model, not the file name of the host.
      Tools  = I edit this photo (crop, restore, stickers, remove BG).
      AI     = I generate a look (beauty, funny, different, tell, pack, remix).
      Share  = I leave with a file (export) — not a Create tile.
P4. Phone portrait: 2 columns max for tiles. Phone landscape: 2-pane or 2
    columns with a minimum tile height (~140dp), never 3-up postage stamps.
P5. Tablet: list | preview (or list | grid). Not a stretched phone.
P6. Actions are buttons. Sentences are not buttons.
P7. Brand yes (color, icons, voice). Layout numbers from the bible are optional.
P8. Empty and error states use the user's photo or an honest empty — never a
    meme template pretending to be their work.

7. SUCCESS BAR
------------------------------------------------------------------------------

A reviewer can:
  1. Open Create → Tools and find Editor / Stickers / Remove BG in one glance.
  2. Open Create → AI and tap Beautiful or the six-look pack without scrolling
     past a wall of chips.
  3. Tap Export and get Take photo / Gallery, then see THEIR photo.
  4. Not find Remix under Tools.
  5. Rotate the phone on Create and Explore and still tap a tile comfortably.
  6. On a tablet, see list | preview, not a poster of stock art.
  7. Save / Share as real buttons on results.

When those seven are true, the UI pass is done — bible or not.
